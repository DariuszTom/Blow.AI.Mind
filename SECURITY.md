# Security Policy

Blow.AI.Mind generates prompt-injection test material for authorized testing of AI agents in isolated environments. It must not be used against systems you are not permitted to test.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/DariuszTom/Blow.AI.Mind/security/advisories/new) rather than public issues.

Include a description, affected version, reproduction steps and potential impact. You should receive a response within a few days.

Examples of in-scope issues:

- Generated passwords leaking into the workbook, manifest, logs or exceptions.
- Weak or predictable randomness in markers, data or passwords.
- Built-in injection scenarios that exfiltrate data to hosts other than the configured beacon.
- Real (non-fictional) secrets committed to the repository.
